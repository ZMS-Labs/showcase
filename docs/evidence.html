How to read this portfolio

What the examples
actually show.

Some of what you’ll see here is an early design, some is a real part of an app running on made-up content, and some is a recorded result. This page says which is which for each project, what hasn’t been tested yet, and where the fonts, illustrations and licenses come from. AI tools write the code. I decide what each project is for and check what comes back. No real agreement, legal file, portrait, game capture or AI model file appears anywhere on this site, and the site has no analytics or forms.

Steno

My workspace for following a contract question across the agreement and back to the words that answer it.

Two of Steno’s drafting checks ran on four made-up clauses, finding two problems before the edits and none after. The archived prototype came out of work in a design tool, Claude Design, and the Hallmark emblem (Steno’s mark for a grade and what backs it) is shown with no assessment behind it. The case page’s account of how Steno was researched comes from private records; its published summary is design-research.json.

SaveBench

AI models design factories in the video game Satisfactory to meet a challenge, and the game itself measures what each factory delivers.

An AI agent designed the factory in the two trials on 2026-09-09. It was given only the challenge and the tools every contestant gets, and the record shows its design used only those. In the first trial, a sample factory that should have delivered showed zero output, so the measuring tool had failed its own check and nothing was judged. After the repair, the same design missed a delivery target in two of its three two-minute measurement windows, and that FAIL is kept as recorded. Later records show that on 2026-09-13, factories designed by AI models passed a harder challenge in the game with faster belts allowed. A newer test, where production has to keep running while nobody touches the factory, had no passing session by 2026-09-23. Dates are UTC, as in the run records. None of this was run again for this site, and none of it ranks the models.

Epistemic Skills

Seventeen written methods an AI agent (an AI tool that carries out a multi-step task on its own) can load when a task calls for one.

At this site’s first publication, a check compared the files the site served with the files meant to be published. The task record names the method as Did It Land, which follows a change through to its result, and anyone can rerun the check. The recorded task doesn’t run an agent or show that agents do better with the methods.

Fleet Orchestrator

The workspace I’m designing to keep each AI agent’s identity, conversation, tasks and reviews in one place.

Three of the project’s own tests passed on its review gate, which holds an agent’s work back while a serious problem found in review is still open. The gate decides whether work may move on, which is a different question from whether it is finished.

Neuraxic

I’m shaping Neuraxic so a story’s prose, people, places and rules can develop together.

Five of the project’s own tests passed. Two check what a version of the story can see, at an earlier point and after a what-if version splits off from the main story. One checks that a new detail that conflicts with the story stays a proposal until the author accepts it, and two check that repeating an acceptance gives back the original record. A detail can be visible in the story without being canon, the version of the story the author has settled on.

Krewcible

I wanted to shape a character out of choices I could see and change before anything is generated.

The 36-second recording shows the editor’s own controls in a test page with made-up choices: the list grows from four choices to eight, and the written description follows each change. The description panel is a readout added for this study to show the text the product composes. No test was run, and the study shows neither image generation nor whether the product saves the work.

Gridiron

I want the commentary for a football video game to follow what happened on the field, so Gridiron writes each play into a record first, and the commentary is meant to work only from that record.

Two recorded runs of one made-up drive gave the same record of events, and 44 of the snapshot’s tests passed, with no AI model running. Gridiron has not yet been tested against the real game. How accurately it reads a game screen, and how accurate its commentary is, have not been measured.

See the replay and what is still unmeasuredRaw record (JSON)

Enaction

In Enaction you pick which character is speaking, and that choice decides whose memory the turn can change.

Twelve of the project’s own tests passed with no AI model running: the memories a scene creates go to a character, never to you as the player. One takes a fingerprint (a code computed from the exact data) of your profile and memories before a scene and finds both unchanged afterward, and a control shows the fingerprint changes when the data does.

See what the twelve tests checkedRaw record (JSON)

Poiesis

I wanted several apps to share one service for generating text and images.

Eight of the project’s own tests passed with no AI model running: a returned file is exactly the one that was made, files expire after 24 hours whether or not anyone collects them, and a stored prompt becomes unreadable once a job finishes. Nothing here proves a stored copy or backup was physically erased, or that a scheduler clears expired files on its own.

Design and type provenance.

The site uses the same typeface and colors as the rest of ZMS Labs, and its page layouts were made with AI tools under my direction. The Gridiron and Epistemic Skills illustrations were made with OpenAI image generation. Both are AI-generated conceptual artwork, so they contain no screenshot, measured result or exact technical diagram. Their labels are ordinary page text that you can select, and screens from each product keep that product’s own look.

Archivo, the site’s typeface, is bundled unmodified under the SIL Open Font License, from Google Fonts. Steno’s prototype images use Source Serif 4, Inter and IBM Plex Mono, and Krewcible’s study uses Instrument Serif, Space Grotesk and JetBrains Mono. Fleet Orchestrator’s and Neuraxic’s images use the fallback fonts their own code specifies. The product fonts appear here only as pixels in images; where each came from, and its original notice, are kept with the private preparation records.

All four silent recordings have descriptive captions and selectable transcripts. Each shows real use of the interface with no generated frames, and captions on the images and recordings say where the content is made up.
