Gridiron · Event reconciliation & grounded commentary

Make the event record
earn the commentary.

A broadcast companion needs more than fluent language. It needs a defensible account of what happened. This research application separates observations, event state, supporting facts and the language produced from them.

Work shown Reproducible synthetic replayStage Research source candidate

Separate what happened from what to say.

Ambiguous or changing observations can produce duplicate, premature or incorrect commentary. Gridiron's architecture places an event reconciler and a canonical ledger before the producer and language path.

The synthetic replay uses a deterministic text provider. Fact packets and a claim guard constrain that path; the language model is not the authority for game state. Optional capture, save and speech integrations have their own validation requirements.

Repeatability is one claim. Accuracy is another.

Two runs produced the same canonical event-ledger hash. The observed event statuses and count matched the full synthetic oracle, with no duplicate commitments.

During preparation, report values that had not actually been measured were changed to explicit null values with NOT_MEASURED labels. A stable replay cannot establish perception accuracy or factual-error rates in commentary.

Four regression cases now reject unsupported accuracy claims, partial event oracles, absent oracles and mismatched event counts.
