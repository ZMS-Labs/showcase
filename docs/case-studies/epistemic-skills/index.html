In plain terms.

An AI agent can offer a plausible cause for a bug that keeps coming back, or change a setting and never look at whether the app picked it up. Epistemic Skills is seventeen written methods (the repository calls them skills) that an agent can load when a task calls for one, with the source and eleven releases public since July 2026.

The walkthrough above shows one real use: checking whether this site's first full publication shipped the files it said it did.

The method that fits

Triage

Compare competing explanations, look at the relevant evidence, and use a targeted test to narrow the cause. Then carry the supported repair through to verification.

A supported cause and a checked repair.

How I think AI should be managed.

I treat AI as a lever, and keep the authority outside it. Steno, the contract review case on this site, is designed around that split: language models help at the edges, such as sorting documents or putting findings into plain English, and never decide what changes in a document or whether a result goes out. Steno's case study also says its build used these methods: in one review, AI reviewers tried to break a claim and caught an earlier write-up overstating what one of its tools verifies.

These methods apply the same rule to reasoning. A model can propose a cause or a verdict. What settles it is something observed, a check that gives the same result every time, or a named person who accepts the result, and the decision to release stays with whoever owns the outcome.

Nothing is done until it is observed where it runs. A passing check of the source, a behavior seen while the program runs and an outcome a user accepts are different levels of evidence, and the methods tell the agent not to let one stand in for another. The methods also keep their own process in proportion, so routine work skips all of this: fixing a typo does not need a review panel. The heavier methods are for questions where a wrong answer costs something.

Consequential decisions, long tasks and handoffs get written records that outlast the session, so nothing rests on a chat that vanished. The agent also says which method it used and what it added, because naming a method is not evidence that it helped.

A decision worth a closer look.

Check the bytes that ship.

Constraint
The site's file list recorded a fingerprint, a SHA-256 hash, for each file, taken from the local copy. The repository calls this list the manifest; it has nothing to do with the manifest method. Git was set to change line endings when text is committed, so the committed bytes could differ from the local ones.
Choice
Check the list against the files Git committed, rebuild it from those bytes, then compare the files the live site served with the committed fingerprints.
Tradeoff
More work than trusting a local success message, in exchange for knowing the published files are the intended ones.

The seventeen methods, and what each is for.

The package holds seventeen methods: one usage guide and sixteen disciplines, the methods that do the work. The guide, epistemic, sets the routine the rest assume: find a method that fits, load its instructions, apply it, say briefly what it contributed, and carry on with the task.

Each method says when to use it, what it should hand back and when to stop. It earns its place only if it settles a question or changes what happens next. The tables follow the four groups of the wiki catalog, and each row names the method by its exact directory in the public repository.

Begin and examine the reasoning

MethodThe question it helps answerWhat it hands back
epistemicHow should these methods be used here?The routine above, applied only as far as the task needs.
metacognateIs our reasoning aimed at the right outcome?A corrected assumption, check or confidence statement. Routine work that can be checked directly skips it.
perspectiveWhat does another focused angle reveal?An insight, an improvement or a bounded finding, handed back to the work.
gauntletWhich judgment holds up when several separate reviews look at it?A reasoned verdict that keeps the material disagreements and says what the reviews covered.

Understand and settle uncertainty

MethodThe question it helps answerWhat it hands back
reconWhat are we missing about the task and what it depends on?A corrected brief or a map of the decisions ahead, before any building starts.
resolveWhich evidence can settle this question?An answer from reasoning, published research or a small throwaway test.
open-questionsWhich consequential choices need the user?Answered questions, and any action held until the user decides.
context-auditAre the loaded instructions conflicting or stale?A diagnosis and a proposed change someone can review before it is made.

Observe, diagnose, and verify

MethodThe question it helps answerWhat it hands back
healthWhat state is the system in now?A status for each part, including what could not be checked. A summary line that reads twelve OK while three subjects were unreachable is the specific failure this exists to prevent.
triageWhat caused this particular failure?A cause backed by an observation that rules out the alternatives, or an open verdict: narrowed, unknown, or not broken after all.
did-it-landDid the change reach the thing that runs?A result observed where the change is used. Until then, the verdict is unverified.
watchWho will notice a problem that appears between sessions?A separate monitor, tested all the way to its alert. The method itself does not keep watch.
evidence-locked-uatDoes a material, user-facing result meet its acceptance criteria? UAT is user acceptance testing.An acceptance verdict tied to what was observed, and no stronger than its weakest required evidence.

Keep work recoverable

MethodThe question it helps answerWhat it hands back
decision-ledgerCan later work recover and recheck this decision?One lasting record with its assumptions and the condition that would reopen it.
manifestDoes this multi-session task need a formal record that survives interruptions?The task's recorded state, with acceptance by someone other than whoever did the work.
write-goalWhat counts as done, and how can the AI tool track it?A written definition of done, which starts only when someone authorizes it.
outsourceCan someone outside this chat do the work from what we hand over?A handoff saved at one fixed version of the repository, and a check of what comes back.

What went into this work.

Direction
For v7, I wanted to fix three problems: agents skipping a method that applied, piling process onto routine work, and stopping before the work was finished.
What I did
I decide what each project is for and check what comes back. For v7, I didn't want the methods working invisibly in the background, so they tell an agent that uses one to say so, even in a single line.
What the AI did
AI tools write the code. A Codex agent built version 7 and reviewed it at my direction, so that review was not independent.
How I work with AI tools

Evidence and limits.

The repository holds the instructions for every method, the checks they share, example scenarios, a maintainer guide, the tooling that packages it for each AI tool it supports, and the receipts from each release. Every explanation on this page can be followed into that source, which is published under GPL-3.0-or-later.

What is real here

The one recorded run on this page is the publication check above, on 19 September 2026. Its record and a script that replays it are public.

The August comparison found no difference between groups. The v6-v7 comparison produced no valid paired trials. Whether these methods improve agent performance remains unestablished.

The release records also note where an AI tool or operating system limited what could be tested. Eight methods (epistemic, metacognate, perspective, did-it-land, health, triage, watch and manifest) say in their own instructions that the conditions for using them rest on design reasoning, and that no shipped set of tests yet shows they are picked up when they should be. That note is in the current source. It was added on 20 September 2026, the day after v7.0.0, so the v7.0.0 release does not carry it.
