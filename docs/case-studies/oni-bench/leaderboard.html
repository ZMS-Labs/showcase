Method · why the board is cautious

Read it as a pilot.

Few runs
With a handful of runs, a single score says little about which model is better, so the board shows every run and a range instead of one number. This follows Agarwal and others, 2021 and Bouthillier and others, 2021. Verified sources checked.
Run to run noise
The same AI model can score differently on the same task from one run to the next, which is why one run never ranks anyone (Bjarnason and others, 2026). Verified source checked.
Progress, not pass or fail
Long tasks are scored by how far a model gets, as in the progress rate of AgentBoard and the game suites of BALROG. Verified sources checked.
Conditions differ
These runs were played on different revisions of the test and with different run limits. That is a limit of this board, stated here as BetterBench asks benchmarks to do. Whether the runs are comparable is Unverified.
