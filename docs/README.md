# ZMS Labs: selected work

A static portfolio connecting project purpose, authentic design, implementation, and evidence.

[Visit the showcase](https://zms-labs.github.io/showcase/) or open [index.html](index.html) locally. No build, model account, external font service, or application backend is required.

## Maintain

Edit the static HTML, `site.css`, and `site.js`; see [maintenance and verification](MAINTAINING.md). Product images are deliberate exports. Keep prototype, component, illustrative, and live-validation claims distinct. The [asset manifest](assets/manifest.json) identifies the exact presentation assets; [EXPORT-MANIFEST.json](EXPORT-MANIFEST.json) inventories the site payload.

The Gridiron download is a reviewed, GPL-noticed research snapshot with no original private Git history. Steno, Krewcible and Fleet implementation source, render scaffolding, private provenance, and original data are excluded. This site does not deploy any featured application.

Visual material follows the [shared documentation standard](https://github.com/ZMS-Labs/.github/blob/main/docs/documentation-standard.md#use-visuals-to-explain). Verify semantic implications against source and inspect actual rendering. Adoption alone does not certify historical content.
