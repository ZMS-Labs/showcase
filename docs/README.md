# ZMS Labs: selected work

A static portfolio connecting project purpose, authentic design, implementation, and evidence.

[Visit the showcase](https://zms-labs.github.io/showcase/) or open [index.html](index.html) locally. No build, model account, external font service, or application backend is required.

- [Steno](case-studies/steno/index.html): archived workspace prototype, current Hallmark emblem specimens and separate recorded drafting checks.
- [Epistemic Skills](case-studies/epistemic-skills/index.html): public method design, source, and evaluation boundaries.
- [Gridiron](case-studies/gridiron/index.html): recorded synthetic replay and a research-source download.
- [Krewcible](case-studies/krewcible/index.html): authentic checkpoint-editor components with exercised synthetic controls.
- [Fleet Orchestrator](case-studies/fleet-orchestrator/index.html): authentic cockpit and glyph design, Surface Bridge responsibilities and a tested review gate.
- [SaveBench](case-studies/savebench/index.html): a historical evaluation that separates invalid measurements from a valid negative result.
- [Neuraxic](case-studies/neuraxic/index.html): branch visibility and author-controlled story continuity.
- [Enaction](case-studies/enaction/index.html): explicit fictional roles and operator-memory boundaries.
- [ZMS Canvas](case-studies/zms-canvas/index.html): recovery and conflict handling in a public fork.
- [Poiesis](case-studies/poiesis/index.html): returned-artifact identity, fixed retention and prompt custody, with an eight-test evidence summary.
- [About this work](about.html): direction, assistance and reading paths.

- [Evidence and attribution](evidence.html): what the artifacts establish, their provenance, and their limits.

## Maintain

Edit the static HTML, `site.css`, and `site.js`; see [maintenance and verification](MAINTAINING.md). Product images are deliberate exports. Keep prototype, component, illustrative, and live-validation claims distinct. The [asset manifest](assets/manifest.json) identifies the exact presentation assets; [EXPORT-MANIFEST.json](EXPORT-MANIFEST.json) inventories the site payload.

The Gridiron download is a reviewed, GPL-noticed research snapshot with no original private Git history. Steno, Krewcible, Fleet Orchestrator, SaveBench, Neuraxic, Enaction and Poiesis implementation source, render scaffolding, private provenance, and original data are excluded. This site does not deploy any featured application.

Visual material follows the [shared documentation standard](https://github.com/ZMS-Labs/.github/blob/main/docs/documentation-standard.md#use-visuals-to-explain). Verify semantic implications against source and inspect actual rendering. Adoption alone does not certify historical content.
